# CAD & AI integrations

## CAD ⇄ GIS (`GeoPandas.Net.CAD`)

```csharp
// CAD drawings have no CRS: georeference with two control points (CAD → world)
var georef = CadGeoreference.FromControlPoints(cad1: (0, 0), world1: (702300, 9311800),
                                               cad2: (100, 0), world2: (702392.4, 9311838.3));
var plan = Dxf.Read("siteplan.dxf", new DxfReadOptions
{
    Georeference = georef,
    Crs = CoordinateReferenceSystem.FromEpsg(32748),
    ClosedAsPolygons = true,
    Layers = new HashSet<string> { "PARCEL", "BUILDING" }   // optional layer filter
});
plan.ToFile("siteplan.gpkg");                                // CAD → GIS

// GIS → CAD: layers from a column, TEXT entities from a label column
Dxf.Write(parcels, "parcels.dxf", layerColumn: "zoning", textColumn: "parcel_id");
```

The reader supports POINT, LINE, LWPOLYLINE (including bulge arcs), POLYLINE/VERTEX (2-D/3-D), CIRCLE, ARC, ELLIPSE, SPLINE (fit/control points), TEXT, MTEXT (formatting stripped), INSERT (as a point with its block name) and 3DFACE/SOLID. Output columns are `layer`, `entity`, `color` (resolved BYLAYER), `linetype`, `text`, `height`, `radius` and `block`. The writer produces R12 ASCII DXF, which every CAD package can open.

> DWG and DGN are proprietary binary formats and are on the [roadmap](../../PLAN.md). For now, convert them to DXF with the ODA File Converter.

## GeoLLM (`GeoPandas.Net.AI`)

`GeoAssistant` sends the dataset schema (columns, types, sample values, CRS and bounds) and the question to an LLM. The model must answer with a JSON plan that uses only whitelisted operations: `filter`, `sort`, `head`, `select`, `area`, `length`, `centroid`, `buffer`, `to_crs`, `bbox`, `nearest_to`, `dissolve`, `groupby` and `count`. GeoPandas.Net executes the plan deterministically. No code generated by the model is ever run, and unknown operations are rejected.

```csharp
using var llm = new OpenAiChatClient(LlmProvider.AzureOpenAI, "https://<resource>.openai.azure.com/", apiKey, "gpt-5-mini");
// or LlmProvider.OpenAI ("https://api.openai.com"), LlmProvider.OpenAICompatible ("https://api.deepseek.com", Ollama, vLLM…)
var assistant = new GeoAssistant(llm);

var answer = await assistant.AskAsync(districts, "Tampilkan 5 distrik terpadat di wilayah Selatan beserta luasnya");
foreach (var step in answer.Plan.Steps) Console.WriteLine(step.Op);
Console.WriteLine(answer.Explanation);
Console.WriteLine(answer.Result);

string summary = await assistant.SummarizeAsync(districts, language: "Bahasa Indonesia");
```

You can implement `ILlmClient` to plug in any other model, including a local one. `OpenAiChatClient.FromEnvironment()` reads `GEOPANDAS_LLM_PROVIDER` (`openai` | `azure` | `compatible`), `GEOPANDAS_LLM_ENDPOINT`, `GEOPANDAS_LLM_API_KEY` and `GEOPANDAS_LLM_MODEL`.

Tested live with Azure OpenAI `gpt-5-mini`. The question "Tampilkan 5 distrik dengan populasi terbesar di wilayah Selatan beserta luasnya dalam m2" produced the plan `filter → sort → area → head → select`, and the answer came back in Indonesian.
