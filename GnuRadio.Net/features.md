# GNU Radio - Fitur Lengkap

GNU Radio adalah framework open-source untuk Software Defined Radio (SDR), Digital Signal Processing (DSP), komunikasi nirkabel, radar, satelit, IoT, dan penelitian RF.

## Fitur Utama

### 1. Arsitektur Flowgraph
- Block-based signal processing
- Stream dan message processing
- MIMO support
- Hierarchical blocks
- Real-time processing

### 2. GNU Radio Companion (GRC)
- Visual drag-and-drop designer
- Auto-generate Python code
- Parameter editor
- Runtime tuning
- Validation dan debugging

### 3. Signal Sources & Sinks
- Analog, digital, noise, file sources
- Audio, file, TCP/UDP sinks
- Time sink, FFT sink, Waterfall sink
- Constellation sink

### 4. DSP
- FIR dan IIR filters
- Resampling
- Correlation
- Matched filtering
- Moving average

### 5. FFT & Spectrum Analysis
- FFT/IFFT
- Windowing functions
- Spectrogram
- PSD estimation
- Waterfall analysis

### 6. Analog Communications
- AM
- FM
- SSB
- CW
- PM

### 7. Digital Communications
- BPSK, QPSK, PSK
- QAM
- FSK/GFSK
- OFDM

### 8. Error Correction
- Viterbi
- LDPC
- Reed Solomon
- Polar Codes
- CRC

### 9. Synchronization
- Timing recovery
- Carrier recovery

- Frame synchronization

### 10. Channel Modeling

### 11. Networking

### 13. RFNoC

## Ringkasan
GNU Radio merupakan salah satu platform SDR dan DSP open-source paling lengkap yang tersedia saat ini, mendukung penelitian, pengembangan, simulasi, dan implementasi berbagai sistem komunikasi radio modern.
