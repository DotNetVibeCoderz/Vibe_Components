# GnuRadio.Net documentation

*Dibuat oleh Gravicode Studios dipimpin oleh Kang Fadhil.* · [Bahasa Indonesia](../id/index.md)

GnuRadio.Net is a Software Defined Radio and DSP framework for .NET 10 modelled on GNU Radio. Blocks are connected
into flowgraphs; a scheduler streams samples between them; visual sinks feed Blazor and Avalonia components.
