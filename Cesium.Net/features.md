# Fitur Lengkap CesiumJS

## Tentang CesiumJS
CesiumJS adalah library JavaScript open-source untuk membangun aplikasi 3D Globe, 2D Maps, GIS, Digital Twin, dan visualisasi geospasial berbasis WebGL.

## 1. Rendering Engine
- 3D Globe Visualization
- Ellipsoidal Earth Model
- Atmospheric Scattering
- Skybox dan Horizon Rendering
- 2D Mode dan Columbus View (2.5D)
- GPU Accelerated Rendering
- Frustum Culling
- Occlusion Culling
- Level of Detail (LOD)
- Instanced Rendering
